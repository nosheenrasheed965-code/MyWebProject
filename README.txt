AURORA STUDIO — HTML / CSS / JavaScript Website

FILES
- index.html: page structure and content
- style.css: responsive styling, colors, layouts, and CSS animations
- script.js: mobile menu, scroll reveal, cursor glow, and current year

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. To customize the site, edit the text in index.html and colors near the top of style.css.

ANIMATIONS INCLUDED
- Scroll-triggered reveal effects
- Moving marquee band
- Floating hero glow
- Morphing organic shape
- Hover lift and arrow interactions
- Subtle cursor glow
- Mobile navigation menu

NOTES
- The contact button uses a demo email address: hello@aurorastudio.example. Replace it with your real email.
- Google Fonts are loaded online; system fallback fonts are included.
- This is a front-end static website; it does not include a backend, database, or form submission service.
